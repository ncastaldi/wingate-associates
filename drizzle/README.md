# drizzle

SQL migrations generated by `drizzle-kit` from `src/db/schema.ts`.

## What belongs here

- Generated `.sql` migration files and Drizzle's `meta/` journal

## What does not belong here

- Hand-written application code
- Edits to an already-applied migration. Add a new one instead.

Generate with `npm run db:generate`; apply with `npm run db:migrate`.
